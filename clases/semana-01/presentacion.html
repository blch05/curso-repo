Viernes · Bloque 3 · Teoría I

        
Variables, asignación (=) y tipos primitivos

        

          

            
const vs. let (y prohibido var)

            
Una variable es un nombre etiquetado que apunta a un dato en memoria RAM.

            
• const (por defecto siempre): no se puede reasignar después de crearla.

            
• let (solo si cambia): contadores, acumuladores, puntajes.

            

              = NO es igualdad matemática: es asignación. Evalúa la derecha y guarda el resultado a la izquierda. Por eso suma = suma + 1 (o suma += 1 / suma++) es totalmente válido.
            

          


          

            
Tipos explícitos de Semana 1 (cero any)

            
const nombre: string = "Lucía";
const edad: number = 24;
const esSocio: boolean = true;

// Union literal (Ej. 2: solo permite estos 4 textos)
const operador: '+' | '-' | '*' | '/' = '+';

// Template string con comillas invertidas (`)
console.log(`Hola ${nombre}, tenés ${edad} años`);

Viernes · Bloque 3 · Diccionario de la Industria

        
null vs. undefined y Scope ({ })

        

          

            
null vs. undefined

            
Ambos representan ausencia de valor, pero con distinto significado:

            
    
              
  • 
                U
                undefined (no asignado): la variable existe, pero todavía nadie le guardó un dato.
              
    • 
              
  • 
                N
                null (vacío intencional): el programador decidió explícitamente que ahí no hay dato todavía.
              
    • 
            

            
let premio: string | undefined;          // undefined
let descuento: number | null = null;     // vacío a propósito

          


          

            
Scope: cada { } es una habitación

            
Las variables declaradas adentro de llaves { } nacen ahí y mueren al cerrar la llave.

            

              Scope Exterior (visible adentro y afuera)
              const nota: number = 8;

              let estado: string = "Desaprobado";
              

                Scope Interior del if { ... }
                const bonus: number = 1; ← solo existe acá

                estado = "Aprobado"; ✓ puede leer/cambiar lo de afuera
              

              

                ✗ Afuera: console.log(bonus) → Error (bonus ya murió).

Operadores (%, ===, &&, ||) y el orden del if / else if

        

          

            
Módulo %

            
Devuelve el resto de la división. 10 % 2 === 0 (par), 15 % 3 === 0 (múltiplo de 3).

          

          

            
Siempre === y !==

            
Compara valor y tipo. Prohibido == (hace conversiones raras en JS).

          

          

            
Lógicos: && · || · !

            
&&: ambos true. ||: al menos uno true. !: invierte.

Viernes · Bloque 4 · Teoría II

        
Bucles (for vs. while) y 3 patrones clave

        

          

            
for — Sabés cuántas vueltas dar

            
// 1. inicio | 2. condición | 3. avance
for (let i: number = 1; i <= 10; i++) {
  console.log(`7 x ${i} = ${7 * i}`);
}

            
Ideal para tablas, sumatorias del 1 a N, FizzBuzz y 3 rondas.

          


          

            
while — Repetís mientras sea true

            
let cuenta: number = 3;
while (cuenta >= 0) {
  console.log(cuenta);
  cuenta--; // ¡SIN ESTO = bucle infinito!
}

            
Si olvidás actualizar la condición, frenás el programa con Ctrl + C.

          

        


        

          

            Patrón 1
            
Anidamiento

            
Podés poner un if adentro de un for para filtrar solo pares o evaluar FizzBuzz en cada vuelta.

          

          

            Patrón 2
            
Acumulador: 0 vs. 1

            
Sumas arrancan en 0 (suma += i). Multiplicaciones arrancan en 1 (fact *= i) — clave para Factorial.

          

          

            Patrón 3
            
Entrada → Proceso → Salida

            
Antes de teclear: definí tus const de entrada, elegí if/bucle, y cerrá con console.log.
