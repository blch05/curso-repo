# Clase 0 — Entrada en Calor (HTML + CSS + Primer Pull Request)

## Objetivo
Perder el miedo a VS Code, practicar el flujo de **Fork + Pull Request**, incorporar nociones básicas de **HTML semántico** (`<header>`, `<main>`, `<section>`, `<footer>`) y **Box Model** (`margin`, `border`, `padding`), y armar tu primera página web simple mientras preparamos la Clase 1 de TypeScript.

## Consigna
Creá dentro de `entregas/<tu-usuario-github>/clase-00/` dos archivos: `index.html` y `styles.css`.

Armá una **página de presentación** (puede ser tuya o de un negocio ficticio de Bovril: peluquería, gimnasio, despensa o rotisería) que incluya:
1. Estructura semántica de página con `<header>`, `<main>` y `<footer>` en ese orden dentro de `<body>`.
2. En `<header>`: un título principal (`<h1>`) y una descripción corta (`<p>`).
3. En `<main>`: una imagen (`<img>` con `alt` descriptivo), una sección (`<section>`) con subtítulo (`<h2>`), una lista de al menos 3 servicios, productos o gustos (`<ul>` y `<li>`) y un enlace o botón (`<a>` o `<button>`).
4. En `<footer>`: datos de contacto, horarios o ubicación (`<p>`).
5. En `styles.css`: colores, tipografía, espaciados (`padding` y `margin`), contenido centrado con ancho máximo (`max-width`) y pie de página al fondo.

## Cómo entregarla
Seguí los 5 pasos de [`docs/flujo-entregas.md`](../../docs/flujo-entregas.md) y abrí tu primer Pull Request antes de la Clase 1.
