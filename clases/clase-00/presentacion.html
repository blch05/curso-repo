Fundamentos Web

Cómo funciona una página web

El navegador (Chrome / Brave) combina tres capas separadas para dibujar y darle vida a cualquier pantalla:

1 · Estructura

HTML

Qué existe en la pantalla. Títulos, párrafos, imágenes, listas, formularios y botones. Es el esqueleto y el significado.

2 · Presentación

CSS

Cómo se ve. Colores, tipografía, espaciados, bordes, sombras y adaptación a celular o computadora.

3 · Comportamiento

JavaScript / TS

Qué hace. Reacciona a clics, valida datos, calcula totales y conversa con el servidor y la base de datos.

Hoy (Clase 0): dominamos las capas 1 (HTML) y 2 (CSS). En la Clase 1 arrancamos de lleno con TypeScript.

Error #1 de Clase 0

Cómo conectar index.html con styles.css

Tener los dos archivos en la misma carpeta no alcanza: hay que avisarle al HTML que cargue tu CSS dentro de <head>.

📁 entregas/tu-usuario/clase-00/
  ├── 📄 index.html
  └── 🎨 styles.css
Si guardás y no ves ningún estilo: revisá que la etiqueta <link> esté dentro de <head> y que el nombre styles.css coincida letra por letra (ojo con mayúsculas). 
<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Barbería Don Pepe</title>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <!-- Acá va tu página: header, main y footer -->
  </body>
</html>

Flujo Profesional

Entregas en 5 pasos (Fork + Pull Request)

Una sola vez hacés Fork y git clone. Después, todas las semanas repetís estos 5 pasos sin tocar main:

Repo del curso → Tu Fork (GitHub) → Tu PC (rama nueva) → Pull Request → ✓ Check verde (Guardián)
01 · SYNC + PULL
Actualizás
Sync fork en GitHub y bajás cambios a tu PC.
git checkout main
git pull origin main
02 · BRANCH
Creás rama
Una rama limpia para la entrega de la semana.
git checkout -b entrega/clase-00
03 · TU CARPETA
Editás solo ahí
Si tocás otra carpeta, el Guardián bloquea el PR.
entregas/<tu-usuario>/clase-00/
04 · COMMIT + PUSH
Subís la rama
Guardás una foto de tu trabajo y la subís a tu Fork.
git add .
git commit -m "feat: clase 00"
git push origin entrega/clase-00
05 · PULL REQUEST
Abrís el PR
Completás la plantilla + declaración de IA y verificás check verde.
Compare & pull request → ✓ evaluar-pr

Práctica · Entregable 0

Consigna de la Clase 0

Creá entregas/<tu-usuario-github>/clase-00/index.html y styles.css con una página de presentación (tuya o de un comercio local):

  • 1Estructura semántica real: <header>, <main> y <footer> en ese orden dentro de <body>.
  • 2En <header>: título principal (<h1>) y descripción corta (<p>).
  • 3En <main>: una imagen (<img> con alt), una <section> con <h2>, lista (<ul>/<li>) y un <a> o <button>.
  • 4En <footer>: horarios, dirección o datos de contacto (<p>).
  • 5En styles.css: colores sobrios, buen padding, contenido con max-width centrado y pie de página al fondo.
