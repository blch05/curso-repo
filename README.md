# Bootcamp de Programación Web desde Cero (TypeScript + React + Supabase + Express).

Repositorio oficial del curso práctico de 12 semanas. Acá encontrás todas las clases, presentaciones, documentación y el espacio de entregas mediante **Pull Requests**.

## Estructura del Repositorio

- [`docs/`](./docs/) — Programa oficial, guía de instalación, flujo de entregas (Git/PRs) y diccionario de la industria.
- [`clases/`](./clases/) — Consignas semanales, presentaciones interactivas (`.html`) y recursos permitidos.
- [`entregas/`](./entregas/) — **Única carpeta habilitada para tus Pull Requests** (dentro de `entregas/<tu-usuario-github>/`).

## Reglas de Entrega

- No se permite pushear directo a `main` ni mergear tus propios PRs.
- Cada PR debe modificar **únicamente** archivos dentro de `entregas/<tu-usuario-github>/`.
- Completá siempre la plantilla del PR (incluyendo la declaración honesta de uso de IA).
